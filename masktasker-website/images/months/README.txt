IMAGES FOLDER STRUCTURE
========================

This folder contains all images for monthly submissions.

Structure:
  images/months/month1/    - Images for January 2024
  images/months/month2/    - Images for February 2024
  images/months/month3/    - Images for March 2024
  ... and so on

SUPPORTED FORMATS:
- JPG/JPEG (recommended for photos)
- PNG (recommended for graphics with transparency)
- GIF (for simple animations)

RECOMMENDATIONS:
- Keep image files under 2MB for fast loading
- Use descriptive names like "team-name-1.jpg"
- Recommended image size: 1200x800 pixels or similar
- Images will be automatically resized by the browser

HOW TO ADD IMAGES:
1. Create a folder for your month (e.g., "month1")
2. Copy your team photos into that folder
3. Reference them in your month's JSON file

Example:
  "images": [
    "images/months/month1/tower-titans-1.jpg",
    "images/months/month1/tower-titans-2.jpg"
  ]
